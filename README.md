このゲームは学科ライブラリを使用して制作したローグライクアクションゲームです
◆開発期間：
2025年5月～2025年7月末　（２年前期）

◆操作タイプ：
キーボード＆マウス

◆ゲーム概要：
ランダムに生成されるブロックで構成されたステージを、銃をもったプレイヤーが敵を倒したりギミックを攻略し
道中で集めたコインでゴール毎にステータスをアップグレードしていき、敵が強くなっていったり１ステージが長くなり
難しくなっていくダンジョンをクリアしていくゲームです。

◆こだわりポイント
このゲームでは、**ステージがランダム生成され、スタートからゴールまでが必ず部屋の端から端まで繋がるように生成されるシステム**に力を入れました。  
ダンジョン生成処理は **Scene/RoomScene.cpp の 741 行目付近の create_room() 関数**で行っています。  
（コード内のコメントには制作当時の遊び心が含まれています）

一人称カメラクラスと三人称カメラクラスをつくり、カメラを切り替える処理を実装しました。
初めての3Dゲームの個人製作であり、カメラの一人称と三人称切り替え時に視点がずれてしまったり、
プレイヤーが銃を撃った時に弾の飛んでいくベクトルがずれてしまう所で修正に苦戦しました。

いまの三人称視点は注視点がプレイヤーとなっているため前方の敵が見えづらく銃弾が当てづらくなっています。
注視点はプレイヤーの右辺りにしたかったのですが知識不足により実装することができませんでした。
今後三人称視点の銃を使うゲームを作ることがあれば実装にチャレンジしていきたいです。
